# AI visibility reports

Assume the reader is an agency prospect unless the user specifies another audience.
Reuse the requested format and prior decisions. If the format is unclear, ask
whether they want a one-page or comprehensive report. Start gathering the
selected brand’s scan evidence while they decide.

| Request | Guide | Default deliverable |
| --- | --- | --- |
| One-page brief | [One-page report](references/one-page.md) | One US Letter PDF page |
| Comprehensive report | [Long-form report](references/long-form.md) | Self-contained HTML with section navigation |

Follow the selected guide's workflow and the [report evidence rules](references/report-evidence.md).
Before drafting, inspect its bundled HTML template. Use the user's design when
supplied and consult the [component catalog](assets/report-components.md) as needed.
Disclose any missing template or evidence. Render and inspect the requested file
with the client's tools, return it, and state any checks you could not complete.
Report generation authorizes analysis and file creation only.
