# HappyFox AEO Plugins

This repository contains the official **HappyFox AEO plugin** for **Codex,
Claude, and Cursor, grokbot**. It includes the plugin manifests, MCP connection
configuration, skills, and report templates that connect your AI assistant to
[HappyFox AEO](https://www.happyfox.com/aeo/).

The plugin brings HappyFox AEO analytics and workflows into your assistant,
so you can analyze your brand's visibility in AI answers, investigate gaps, and
create reports from tracked results. With the appropriate permissions, you can
also manage tracked prompts and competitors through the same connection.

## What you can do

- See how your brand appears in AI answers and how its visibility has changed.
- Compare your brand with competitors and find prompts to investigate.
- Explore answers and citations to understand visibility gaps and develop
  evidence-backed next steps.
- Create a one-page brief or a comprehensive AI visibility report.
- Add or delete tracked prompts, and add, edit, or delete competitors with the
  appropriate permissions.

## Installing

Install **HappyFox AEO** from the plugin directory for your assistant.
You need a HappyFox AEO account with access to a brand. Sign in and
approve the requested access when prompted.

### Claude

In Claude or Claude Desktop, open **Plugins** in the sidebar, find
**HappyFox AEO** in the directory, and select **Add**. If your account still
shows **Customize**, open **Customize > Plugins > Discover** instead.

In Claude Code, use `/plugin` to browse plugins, search for **HappyFox AEO**,
and install it.

### Codex

Open the Plugins directory in Codex, find **HappyFox AEO**, and install it.
In the Codex CLI, run `/plugins` to open the plugin browser. Complete the
connection setup when prompted, then start a new chat.

### Cursor

Open **Customize** in Cursor to browse plugins, or visit the
[Cursor Marketplace](https://cursor.com/marketplace). Search for **HappyFox AEO**,
install it, and complete the connection setup.
See [Cursor's plugin documentation](https://cursor.com/docs/plugins) for details.
